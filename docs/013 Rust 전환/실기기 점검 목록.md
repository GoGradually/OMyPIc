# 0.3.0 실기기 점검 목록 (Windows, macOS)

0.3.0은 Backend(Java → Rust), 저장소(MongoDB → SQLite), 데스크톱 셸(Electron → Tauri), 무료 음성(운영체제 음성 → 로컬 모델)이 모두 바뀐 버전입니다. 개발 중 실제로 실행해 본 환경은 Linux(Chromium, WebKitGTK)와 GitHub macOS 러너의 Safari(음성 모델만)뿐입니다. 설치본을 Windows와 macOS 실기기에서 실행해 본 적은 없으므로, 릴리스 전에 아래를 순서대로 확인합니다.

- 설치본: GitHub Actions `Release` 워크플로 실행 결과의 `installer-windows-x64`, `installer-macos-arm64`.
- 데이터 폴더: Windows `%APPDATA%\omypic-frontend\omypic-data`, macOS `~/Library/Application Support/omypic-frontend/omypic-data`. 0.2.x와 같은 폴더입니다.
- 로그: 데이터 폴더의 `logs/omypic.log`. 문제가 생기면 이 파일과 화면의 메시지를 함께 남깁니다.
- 각 단계의 "기대"와 다르면 거기서 멈추고 기록합니다. 뒤 단계가 앞 단계에 기대는 곳이 많습니다.

## 1. Windows

데이터와 API Key가 들어 있는 0.2.1이 설치된 PC에서 시작하면 업그레이드까지 한 번에 볼 수 있습니다.

## 2. macOS (Apple Silicon)

GitHub macOS 러너의 Safari 27.2에서는 세 음성 모델이 정상으로 올라갔습니다(Kokoro 로드 2.7초, Supertonic 4.3초, Whisper 3.1초, 최대 메모리 약 2.4GB). Safari는 앱의 WKWebView와 같은 시스템 WebKit을 쓰지만, 설치한 앱 안(`tauri://localhost`)에서 실행해 본 것은 아닙니다. M6이 그 확인입니다.

| # | 할 일 | 기대 |
|---|---|---|
| M1 | 0.2.x에서 내보내기를 하고 끈다. DMG의 `OMyPIc.app`을 응용 프로그램 폴더로 끌어 0.2.x를 바꾼다. 연다. | 서명이 없어 "손상됨" 경고가 뜬다. `xattr -dr com.apple.quarantine /Applications/OMyPIc.app` 실행 후 다시 연다. |
| M2 | 창이 뜨는지 본다. | "준비 완료"가 뜨고 모델 목록과 질문 그룹이 보인다. 페이지(`tauri://localhost`)가 `http://127.0.0.1:<포트>`의 Backend에 닿았다는 뜻이다. 안 되면 `logs/omypic.log`를 남긴다. |
| M3 | 설정을 연다. | 키체인이 로그인 암호를 묻는다(0.2.x가 만든 `OMyPIc` 항목). "항상 허용"을 고르면 키가 보인다. 묻는 횟수를 적는다. `저장 + 검증`이 성공한다. |
| M4 | 마이크 `권한 요청`. | 한국어 안내문이 있는 시스템 허용 창이 한 번만 뜬다. 조용히 거부되면 `tccutil reset Microphone com.omypic.app` 후 다시 한다. |
| M5 | 가져오기, 내보내기, 룰북 올리기(W7~W9). 키 입력란에 Cmd+V. | Windows와 같다. 창은 본 창에 붙은 시트로 뜬다. |
| M6 | 활성 상태 보기에서 앱의 "Web Content" 프로세스를 찾아 두고, `local-models`를 지운 뒤 AI OFF로 `세션 시작`. | 92MB 파일을 받은 뒤 1분 안에 세션이 열리고 질문이 들린다. 메모리는 1GB 안팎이다. **파일이 있는데도 "영어 음성 합성 모델을 준비하고 있습니다"에서 3분 넘게 머물거나, 메모리가 4GB를 넘거나, 창이 하얗게 되면 실패**다. 시간과 메모리를 적는다. |
| M7 | W13~W21을 그대로 한다. | Windows와 같다. 세 모델을 올렸을 때의 메모리와, Windows보다 눈에 띄게 느린 문장이 있으면 적는다. |
| M8 | `local-models`를 지우고 네트워크를 5Mbit/s쯤으로 제한(Network Link Conditioner)한 뒤 W14를 한다. | 퍼센트가 멈추지 않고 올라가며, 60초가 지나도 내려받기가 끊기지 않는다. |
| M9 | 빨간 버튼으로 창을 닫는다. Cmd+Q, Dock > 종료도 해 본다. 모델을 받는 중에도 한 번. | 앱이 끝나고 `OMyPIc` 프로세스가 남지 않는다. 받는 중이면 7초쯤 걸릴 수 있다. 로그 끝에 `Shutting down the backend`가 있다. |
| M10 | 실행 중에 `open -n /Applications/OMyPIc.app`. | 두 번째 창이 뜨지 않는다. |
| M11 | 나중에 0.3.x의 다른 빌드를 설치한다. | 서명이 없어 바이너리가 바뀔 때마다 키체인과 마이크 허용을 다시 묻는다(알려진 동작). |

## 3. 실제 API 호출

개발 환경에 API Key가 없어 OpenAI와 Anthropic을 실제로 호출해 본 적이 없습니다. 요청 형식은 각 SDK 소스와 대조해 맞췄습니다.

| # | 할 일 | 기대 |
|---|---|---|
| A1 | 설정에서 두 키를 `저장 + 검증`. | 둘 다 성공한다. 틀린 키는 실패 메시지가 나온다. |
| A2 | OpenAI 피드백 모델로 한 턴(STT, 피드백, TTS 모두 OpenAI). | 0.2.x와 같은 내용과 형식의 피드백이 오고 소리가 난다. |
| A3 | Claude 피드백 모델(`claude-opus-5-5` 등)로 한 턴, STT/TTS는 로컬. | 피드백이 온다. Claude 키만 있어도 세션이 시작된다. |
| A4 | 룰북을 올리고 피드백에 반영되는지, 오답노트가 쌓이는지 본다. | 0.2.x와 같다. |
